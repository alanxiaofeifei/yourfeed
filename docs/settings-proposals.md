# 设置体验改进提案（仅提案，未实施）

任务入口：[Draft PR #8](https://github.com/alanxiaofeifei/yourfeed/pull/8)。

这些建议基于现有「我的偏好 / AI 与接口 / 存储与归档 / 部署与域名」四个分类、独立的「内容来源」和右上角账户菜单。**本文件不是功能承诺或实施授权**；当前 PR 的引导与账户入口修复不代表下列功能已实现。后续须先确认范围、验收和优先级，不改变单所有者、独立实例或现有访问控制。

工作量：S = 局部 UI / 文案；M = 多组件状态与验证；L = 跨前后端设计与较广回归。风险不只指安全，也包括误导、草稿丢失和额外费用。

| 优先级 / 提案 | 用户价值与建议交互 | 工作量 | 风险与边界 | 建议验收 |
| --- | --- | --- | --- | --- |
| 1. 分类卡片显示配置状态 | 在分类卡片旁显示「未配置 / 已保存 / 有未保存更改」，让用户知道下一步在哪里，而非只看当前选中分类。状态来自现有已读配置，读失败明确标为「状态暂不可用」。 | M | 中：默认值不等于保存成功；已保存不等于测试通过。不得根据输入框清空、toast 或 tour 完成推断配置成功。 | 四语言状态完整；加载失败不显示绿色完成；切换分类不丢草稿。 |
| 2. 统一保存与离页提示 | 统一偏好和 AI 表单的保存反馈、禁用时机及脏表单提示；顶部和底部按钮仍可共用同一次保存，明确测试不会保存。 | M | 中：重构可能导致重复提交、丢输入或错误显示已保存；密钥草稿只留内存，不为恢复写入浏览器存储。 | 保存失败保留输入；未改动不提交；重复点击不产生并发保存；取消离页停在原表单。 |
| 3. AI 最小配置与高级选项分层 | 先展示提供商、模型、密钥、测试与保存，把协议、参数和自定义费率等放入可展开高级区域；必要字段仍须校验。 | M | 中：折叠不能掩盖错误或自定义费用，不能自动切服务商或启用 AI。 | 错误会展开并聚焦对应字段；RSS-only 用户可跳过；已有高级设置保持不变。 |
| 4. 费用与测试结果解释卡 | 就近区分本站估算预算、上游账单、免费层配额以及「当前草稿测试 / 已保存 / 自动阅读开关」；显示本次测试适用范围，不把历史连接成功当永久有效。 | M | 中：价格与免费规则会变，不能保证预算能阻止上游收费；展示来源和核实日期，不自动发测试请求。 | 改变模型、地址或密钥后旧测试不再显示为当前有效；无 key 不产生请求；文案不承诺免费。 |
| 5. 来源与 API 配置互相引路 | 在 YouTube key 卡说明还需添加频道和更新；在来源页缺 key 时提供返回 AI 分类的明确入口，并保留原编辑上下文。普通 RSS 不出现 key 必填提示。 | M | 中：跨页导航易丢草稿；保存 key、订阅频道、成功读取是三件事。 | 往返前有脏表单确认；无需 AI key 可完成 RSS；只有真实读取证据才标验证成功。 |
| 6. 存储与归档的安全摘要 | 把设备缓存、服务器正文保留、到期提醒和下载归档分开说明，强调本地缓存不是备份；展示范围与失败后的重试入口。 | M | 中：清理入口可能误删数据或让用户误信已有备份；此提案不授权新增自动清理或改变保留期。 | 导出动作无 AI 调用；说明含/不含哪些数据；没有可验证备份就不显示「已备份」。 |
| 7. 设置内查找与无障碍定位 | 提供仅搜索本地设置标签的查找入口，跳到相应分类并聚焦标题或字段；兼容键盘、读屏与窄屏长译文。 | S | 低：只搜索静态界面文案，不索引密钥、邮箱、用户目标或阅读内容；跳转仍遵守未保存确认。 | 四语言关键词均可查到对应设置；无结果有反馈；200% 缩放与手机下不横向溢出。 |

## 建议顺序与非目标

先评审 1、2、4（状态与保存语义），再按实际用户反馈考虑 3、5、6、7。不把七项同时塞入 onboarding 修复。

非目标：新增账户注册、共享多租户、变更会话权限或 recent-auth、修改数据库 schema、自动订阅、代用户配置付费、自动 provider fallback，以及任何生产或成员实例部署。账户身份与退出仍只由右上角账户菜单负责；左下角只保留非交互阅读隐私说明，不能宣称端到端加密或管理员无法访问。
